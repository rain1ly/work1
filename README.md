# 高校实验室安全规程问答

> 面向高校实验室安全场景的 RAG 知识库问答系统
> 第九届传智杯 · AI 创新应用挑战赛（个人赛）参赛作品

一个能回答「浓硫酸溅到手上怎么办」「乙醚能不能放普通试剂柜」这类问题的智能助手。所有回答都**可追溯**——直接指出依据是哪份文件的哪一章节，**查不到就明说查不到**，并且高危操作附带**已审核的示范视频**。

---

## 一、要解决的问题

高校实验室安全事故的根因，往往不是学生不知道规定，而是**规定太多、太散、太专业，关键时刻找不到**：安全手册、危化品管理条例、MSDS、设备操作规程、应急预案分散在十几个文件里，出事了才翻已经来不及。

本项目把它们整合成一个能用大白话提问的助手，并提供三个关键保障：

- **答案可溯源** —— 每条结论都能定位到原文
- **不知道就拒答** —— 低置信度时明确说「未找到」，绝不编造
- **操作有示范** —— 高危操作附带已审核的示范视频

## 四、快速开始

### 方式一：零配置跑通（推荐先跑这个）

不装任何第三方库、不配任何 API Key，直接看完整链路效果：

```bash
python scripts/demo.py
```

会依次演示：知识库内提问（带引用 + 视频）、限定渠道提问、以及超范围提问被正确拒答。

### 方式二：启动网页界面

```bash
pip install -r requirements.txt
python -m src.ingestion.indexer        # 建库
uvicorn src.api.app:app --reload       # 启动服务
```

浏览器打开 <http://127.0.0.1:8000>，即可选择渠道、提问、看引用与视频卡片。

### 方式三：启用真实模型（质量最好）

```bash
cp .env.example .env      # 填入 LLM_API_KEY / VL_API_KEY
# 并在 .env 中设置：
#   EMBED_BACKEND=bge     启用 BGE-M3 向量化（需下载模型）
#   USE_RERANKER=1        启用 BGE-Reranker-v2 重排
```

## 七、三个关键设计决策

这三条是答辩时最值得讲的，它们是「能不能拿分」的分水岭。

**1. BM25 用绝对分数饱和，不按结果集归一化。**
归一化会让每次检索的第一名永远拿到满分——哪怕检索结果全是垃圾。这会让拒答判据彻底失效。改用 `raw / (raw + k)` 后，超范围提问的分数会真实地掉到 0.3 以下。

**2. 拒答用双闸门：覆盖率 + 置信度。**
只看分数会漏掉「用漂亮分数硬答不相关问题」的情况，所以增加一道「关键术语覆盖率」硬门槛：用户问题里的实词如果几乎没在知识库中出现，直接拒答。这是安全领域最该有的保守。

**3. 渠道过滤作用在检索阶段，不是界面筛选。**
建索引时给每条切块打 `channel` 字段，检索时先按渠道缩小候选集再排序。只在界面上筛已经召回的结果，等于第一次召回就是错的。

## 九、必须遵守的两条底线

**1. Git 提交历史会被核查。**
官网明确要求细粒度提交，**禁止一次性把全部功能提交上去**。本仓库当前已有 23 次按模块拆分的提交，后续请继续保持这个粒度，每次提交对应一个功能模块。

**2. 安全内容的红线。**

- 操作示范视频**一律不用 AI 生成**，只用经过人工审核的权威素材，并登记来源机构 / 审核人 / 审核日期。

- 涉及伤口、事故的问题只输出规程中的处置流程与求助渠道，**不做医疗诊断**。
- 界面需明示「以规范条款为准」，识别结果需标注「仅供参考」。
